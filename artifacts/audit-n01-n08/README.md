## 测试调整说明

既有 G09 测试曾向同一活动同一会员换键创建第二次发送，这正是本轮需禁止的行为。现在用三个合成会员分别检查成功、未知回执和停发，原有超时、签名、去重、乱序、停发断言保留；额外断言同一业务换键返回原意图。原有 63 项测试数量未减少。

## 兼容和交付范围

旧内容缺生成事实必须重新生成；旧触达审批需编辑并重新批准。历史消费及意图保留；无法归属的旧意图保守阻止新分配。失败或未知的真实渠道意图不自动释放预算；对账界面尚未实现。

`orderSources` 可登记门店预期订单源；没有登记、没有任何导入或订单记录的外部系统无法自动发现。JSON 锁内校验不是生产数据库事务验收。

本轮使用已有 node_modules，没有干净安装或浏览器点击验收，没有真实外部消息、真实模型或生产数据库。生产 OWNER 初始化、业务 worker、完整客户界面等仍有内部开发工作，见 docs/CAPABILITIES.md 和 docs/BLOCKERS.md。
