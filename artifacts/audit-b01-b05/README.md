## 修复范围

- **B01/B03**：业务订单键包含租户、门店、来源、外部编号。修订不算新订单；退款和核销采用相同身份。归因在仓储锁内绑定来源与内部订单版本，后续同号异源订单不能扩大旧证据。旧歧义证据保留 unknown，不能因订单被取消或处于查询期外而猜测来源。
- **B02**：第一方触点采用含边界的支付前七天窗口，取最后一次合格触点。订单验证券优先，不套触点窗口；支付后核验可以在之后的报告出现。未来证据、无效时间和自报来源不进入主归因。结果记录模型及窗口。
- **B04/B05**：保存时拒绝错误类型、空串、无时区、非法日历日期和错误区间。执行时再次检查价格、素材和品牌有效期；即使历史审批的版本与哈希匹配，错误日期仍不能导出。null、未来生效、恰好到期有独立边界断言。
- **A01**：新增、删除、改名、修改源码，以及锁文件、命令、工具链或日志变化均使旧证据失效；验证期间新增文件也失败。临时小工程只用于验证记录器，不代表应用验收。
- 删除 fixture 中的第二套指标算法，保留格式适配后调用应用引擎。已有数值断言未修改。
