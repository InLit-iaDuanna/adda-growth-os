# 合成夹具，不是业务数据

所有名称、会员、订单与金额为设计测试用合成资料。example.invalid 联系地址不用于实际消息。
golden_dataset.json 含 12 行原始订单（O001 有一次重复）、3 行退款（R001 有一次重复）及 6 个会员。
去重后 11 个原始订单，O007 全额退款，所以合格订单数为 10；O009 部分退款后净额 18000。
M003 在同一营业日的两单不能算跨日复购；其第 3 单全额退款不能算复购。M004/M006 的首购 cohort 不足 30 天。
O001 同时有两个来源，verified_coupon 优先；O010 仅自报来源，应留在 unknown。没有到店客流或成本记录，所以不能填充总体到店或 ROI。
运行 node scripts/verify-fixtures.mjs 校验夹具内数字。它只验证小型离线示例，不负责生产口径、SQL、权限或完整渠道业务；Codex 必须将同样断言放进真实应用测试。
