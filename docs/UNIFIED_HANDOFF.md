## 基线与交付定义
本次完整工程来自用户上传的 `adda-growth-os-source-2026-09-25.zip`，不是从前几轮截图或独立 HTML 猜测重写。不需要应用旧的 `apply.py` 补丁。完整源文件、原有测试、规格和品牌资产均在根工程内；附 `dist/` 可直接用 Node 试用，修改 TS 后必须重新编译。

## 本次具体变化

### 统一界面
运营、语言审核、收银现场核验、顾客 H5 共用 `packages/ui` 主题、SUIWU/ADDA 母子品牌、按钮、表单、错误状态与响应式规则。A 首页进入 B 编排工作区，不切换两套独立应用。删除旧首页并排挂载的重复结构，把原 `ui.ts` 拆到 controller / renderer / page 模块，旧业务接口保留。

门店选择会同时收窄各业务 API；失败显示“未读取”及局部错误，不当作零待办。审核角色不显示生成和负责人批准操作；收银只显示必要核验功能。表单时间按门店时区转换，不再按操作者电脑时区解释，歧义/不存在的夏令时时间拒绝保存。原生对话框包含 Esc 关闭与焦点返回。

### Agent 与业务后端
创建任务时，在同一文件事务内校验门店/工具/步骤/预算/重试上限并固定证据快照、请求哈希和版本。后台 worker 独立推进，不由浏览器计时器模拟执行；通过现有仓储锁串行提交检查点。重启恢复、两 worker 并发、真实子进程在提交前退出都已有测试。撤销成员资格会取消未执行工作，取消后的任务不会被 worker 捡起。契约错误与截止超时不盲目重试；可重试错误只重试失败节点并保留上游输出。

模型式输出只能引用已固定的授权来源与代码算出的指标，不能修改指标值、伪造引用或自行授权外部动作。保留“运行完成”与“业务结论待补/待人工确认”的区别。目前四条固定流程调用七种确定性只读技能，实际模型成本 0；没有承诺 live LLM 已实现。

内容批准/改稿/本地复核前后保存不可变历史快照；并发改稿通过 `expected_hash` 拒绝旧页面覆盖；已有审批失效机制保留。重复导出复用同一批准执行意图。新增带原因的退回审批。旧可编辑 revision ID 继续作为工作文档 ID，批准历史独立 append-only，不破坏旧 API。

注册、同意和来源触点合并到单一事务，避免并发注册返回错误的访问令牌或修改先注册者同意。重复领券复用服务端生成的同一令牌，同会员同优惠只扣一次额度、只计一次领券事件。券预留和现场签到仍不代表权威订单。顾客 H5 提供撤回营销同意与当前标签页访问凭据恢复；不在存储中保留明文联系方式。

## 验证方法与不能声称的部分

实际 `npm test` 构建全工程，执行原 116 项 TS + 4 项整合回归 + 19 项本轮后端/时区回归 + 6 项 MJS 证据校验，共 145 项。最终结果和日志以 `artifacts/unified-2026-09-25/validation.json` 为准；文档不是测试替代物。

`tests/browser_unified.py --dom-harness` 的 89 项检查运行实际生成的 HTML、真实应用 HTTP 路由和独立 JSON 仓储，没有业务成功假响应。包含五种宽度 × 十一个管理页面、编辑/审核/批准/退回、后台任务创建与重新加载、顾客注册领券退订、收银保留、POS CSV 导入与券成交核验。唯一人为响应是专门的 503 读取失败用例。

由于环境禁止浏览器原生 URL 导航，测试把服务器 HTML 装入内存，以独立 Python Cookie jar 转发同样的请求，并嵌入原图字节；这是明确受限的 DOM/HTTP 集成模式，不是原生浏览器 E2E。Cookie/SameSite/CSP/同源策略、跨页面导航和真实 sessionStorage 恢复没有通过此方法验收。普通环境可运行不带 `--dom-harness` 的脚本进一步验证。

网络 `EAI_AGAIN` 导致无法安装锁定 npm 依赖。实际使用 Node 22.16.0、预装 TypeScript 5.8.3 与真实 @types/node 24.0.4 类型定义进行编译，不使用类型替身。`validation.json` 记录实际工具链。旧 lock 指定的干净安装、Docker 镜像实际构建、Safari/Firefox 均未验证。

所有截图和端到端业务数据为明确标注的独立 TEST 合成记录，不是客户营收、商品或联调结果。原有安全扫描为有限静态扫描；AI contract/fixtures 是合成规则验证，不是 live 模型质量。
