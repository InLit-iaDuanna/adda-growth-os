# 尚未完成的交付能力

当前交付限于离线原型。最新测试数量、源码哈希和证据统一见 [能力记录](CAPABILITIES.md)，不在多份文档手工维护。

## 内部研发

- PostgreSQL 适配器、生产事务和迁移尚未实现。Docker 可用也不能替代这些开发工作。
- worker 只有 maintenance handler。业务发送、最终执行前重验、外部成功但本地无回执时的恢复与对账尚未接通。
- 真实模型尚未接入业务技能；缺超时、成本记录和真实任务评测。
- 缺受控的生产 OWNER 创建/邀请入口。演示界面已覆盖主要本地操作，但生产环境仍不能独立完成约定业务流程。
- 触达失败或未知结果会保守保留额度；尚无人工对账及释放预算的界面。不能用新请求键强行重发。

## 外部资料和联调

在内部能力完成后，仍需客户批准的品牌/菜单/素材、POS 样本及来源完整性约定、同意文案、本地语言复核人、WhatsApp 账户和获批模板、明确许可的测试接收人、部署环境及 UAT。

这些外部条件不解释或替代上面的内部研发缺口。没有真实发送或客户验收证据时，不标记 LIVE_CHANNEL_ACCEPTED 或 PRODUCTION_READY。
