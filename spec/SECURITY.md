# 权限、隐私与执行安全

## 角色边界

OWNER 管理品牌规则、预算、连接器、用户、导出和发布权限；GROWTH_MANAGER 在获批范围内创建与审批增长任务；LOCAL_REVIEWER 只负责语言和文化复核；STORE_MANAGER 管理本店现场执行、票据核验和工单；CASHIER 仅核销与必要会员查询；ANALYST 默认只读脱敏分析。
同一个人可以被明确赋予多个角色，但 AI 永远不是审批人。服务端执行资源、范围和操作权限校验，不能只隐藏按钮。

## 五类需要显式批准的动作

发布内容；营销触达；活动/优惠生效；KOC 或奖励承诺；处理涉及补偿/公开争议的客服回复。真正支付、广告竞价、银行卡操作不在 V1 范围。
每个 approval 绑定精确内容和受众快照，设置失效时间。审批后新增人员、改动金额、日期、产品、模板或素材触发重新审批。
执行前再次读取实时政策状态；合法删除/退订的成员从冻结人群中剔除并记录，不因此扩大人群。需要新增成员必须重新生成快照和审批。

## 同意与联系人

会员协议/活动报名/营销同意分别显示；营销选择不默认勾选。记录用途、渠道、来源、文案版本和时间，撤回立即写 suppression 并取消未发送任务；外发 worker 在发送前再核对。
客服会话不是无限营销同意。导入名单必须携带可证明的许可来源，不允许用“导入即同意”开关。
可导出的营销列表也应用同意与抑制规则，并保留审计。没有平台权限时人工流程不能成为绕过退出和频控的后门。

## 数据最小化

不收集本任务不必需的敏感信息，不根据姓名/照片/聊天猜测年龄、性别、宗教、收入或谁与谁交往。可选学校/偏好由本人提供并可改删。未成年人相关活动和资料由甲方事先设定政策，不假设所有校园参与者都是成年人。
品牌资料不能混入会员 PII 的向量库。模型请求与 traces 默认脱敏，不发送可识别联系人列表。业务数据导出、删除和访问由最小权限控制。
部署前由甲方确认适用隐私告知、保存期限、服务商处理安排、跨境处理和校园/活动/素材授权；本规格不替代当地合规审查。

## 防护与故障

采用维护中的 auth 组件，禁止默认生产密码，管理员启用二次验证能力。验证码短时有效、一次性、限速，生产日志不打印验证码。会话 cookie 采用 secure/httpOnly/sameSite 等正确设置；对状态写入实施适当 CSRF 防护。
上传限制大小/类型，隔离与检查；解析/下载外部 URL 使用 allowlist 和 SSRF 防护，避免请求内网/云元数据地址。内容输出转义，禁止不可信 HTML 执行。CSV 导出防公式注入。
供应商 token 加密存储或 secret manager 引用，日志脱敏，支持撤销与轮换。OAuth 有 state、正确 redirect URI 和最小 scope；webhook 验签与去重，回放受窗口/事件 ID 约束。
公开来源/券链接使用高熵 token，避免猜测；会员查询防枚举；核销高并发事务校验。奖励不自动发放，全额退款冲销资格。

## 凭证和测试

没有凭证不得编造测试通过。生产渠道 disabled 默认；所有联调只用明确许可的测试人和预算。禁止在自动化测试里联系真实顾客、发布公开内容或创建真实支出。

## 出故障时

模型不可用：业务台账、手工内容编辑、核销与基础报告仍可用；AI 卡片显示 unavailable。
订单源过期：报告显示截止与不足，暂停依赖新鲜销售的精确建议。
渠道撤权：停止队列，发管理员任务，不绕过授权抓取。
外部发送超时：unknown_delivery，先对账；不能无限重试或伪造成功。
容量/预算不够：阻断活动激活并提示调整。紧急投诉：立即提醒授权人员且保留未确认告警。
全局、租户、活动和渠道层均可暂停外发，暂停后不能有新的未授权 dispatch。
