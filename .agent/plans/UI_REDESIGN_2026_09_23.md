# 工作台视觉改版 ExecPlan

## 目标和用户可见结果

回应用户对前端观感的反馈，重新设计后台工作台及顾客来源页的视觉层级、导航、表单和移动端布局。保留现有业务流程、真实状态和中英／英孟切换。

## 仓库现状与依赖

当前页面由 `apps/web/src/ui.ts` 的服务端 HTML 模板及内联 CSS 渲染，业务仍是本地 JSON 离线原型。上一轮逐项核查已通过 122 项测试；浏览器截图显示 744px 宽下顶栏拥挤、导航横向滚动、指标缺少主次。

## Progress

- 已完成：用 Computer Use 检查改版前总览与内容审批页。
- 已完成：后台视觉系统、导航与总览改版。
- 已完成：顾客来源页改版、桌面和手机视觉复核、英文与孟加拉语切换复核。
- 已完成：类型检查、完整 release validation、CodeBuddy CLI AI 冒烟测试。

## 设计与文件路径

仅在 `apps/web/src/ui.ts` 调整页面结构及样式，保持现有 DOM ID、表单 name、API、授权逻辑和数据计算。使用暖纸色、深绿、陶土色构成统一视觉系统；CSS 图形为装饰，不当作品牌已确认事实。

## 实施步骤

先重做后台框架和总览，再统一模块卡片、表单与空状态。随后改顾客页。重启演示服务，以 Computer Use 操作总览、内容、密集表单和顾客页，在桌面与 390px 手机视口检查，再执行完整验证。

## 验证命令及预期

`npm run validate:release` 应通过全部已有门槛和测试；`npm run test:codebuddy-ai` 只发起一条真实模型请求且保守总量低于 10000。浏览器中不得出现页面溢出、导航不可达、翻译丢失或功能回归。

## 实际验证证据

`npm run validate:release` 通过 typecheck、build、122 项测试、安全扫描、AI 契约和夹具验证；`npm run test:codebuddy-ai` 使用 `deepseek-v4.1-flash` 通过，单次消耗 1 次请求。Computer Use 观察到后台总览、内容审批、顾客反馈和顾客页在桌面及 390×844 下无横向溢出；语言切换保持布局可读。截图由本轮交互直接复核，没有伪造静态截图路径。

## Surprises & Discoveries

手机复核初次发现总览装饰轨道导致页面横向滚动；将装饰图形在手机断点隐藏并为根页面加 `overflow-x:hidden` 后重新加载确认无横向滚动条。

## Decision Log

本轮视觉方向由开发者依据用户反馈选择；不声明该装饰色系是甲方已确认的品牌规范。

D038：视觉系统使用暖纸色、深绿和陶土色建立层级，移动端导航改为网格，避免九个模块被横向滚动隐藏；所有业务状态和事实边界保持原逻辑。
