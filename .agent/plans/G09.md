adapter 单元测试使用模拟 transport；worker 尚未调用 adapter。真实验收不能由模拟取代。

## 实际验证证据
npm run test:g07-g10 与完整 npm test 通过；5 个测试覆盖审批绑定、签名、幂等、单调状态、kill switch 和 adapter blocked/fake transport。官方规则核对见 artifacts/G09/official-check.md；没有真实 provider 请求。

## Surprises & Discoveries
初稿允许 body.status=active 且相信任意 approval_hash，需要全部拒绝。

## Decision Log
默认禁用外发；真实发送只能由服务端凭证、批准快照、受众许可共同开启。

## 回滚与幂等
外发前持久化 dispatching；未知结果不得自动重试；webhook 只更新已存在且匹配账号的 intent。
