## Surprises & Discoveries

端到端测试最初因空生产库提示和后台英文入口缺失而失败；补齐真实可见状态后通过。界面尝试触达时曾发现全保留组错误显示完成，修复空集合判断并在迁移时校正旧状态。晚导入的历史订单也可能错误触发推荐奖励，现按支付与推荐创建时间保守阻断。

## Decision Log

CodeBuddy CLI 仅用于独立合成事实测试，业务运行时不自动发送客户资料给外部模型。无连接器的触达维持 `blocked`，人工任务完成仅说明操作员留证。未排期的活动保留草稿但不得开放。

## 回滚与幂等

本轮没有修改真实业务库或外部渠道。测试数据位于独立 `/tmp` JSON 文件；原始 ZIP 保留，可据原始清单复原源文件。当前目录不是 Git 仓库，回滚代码需使用源压缩包或外部备份。新增迁移对已纠正的触达状态不重复变更。
