# G06 ExecPlan — 会员分群、触达审批与实验

## 目标和用户可见结果

基于真实会员/订单/同意事实计算少量规则分群，冻结受众与持久化 holdout；发送前重新检查 verified contact、marketing consent、退订、频控、安静时段、模板和预算。触达在测试 outbox/manual 状态运行，生产无渠道时不伪造送达；报告按所有已分配成员（含 holdout/未送达）统计并在小样本标 exploratory。

## 实施步骤

1. 规则只查询成员、订单、事件和 consent 状态，不把手机号列表送入 provider；preview 返回 count/coverage/reason。
2. snapshot 保存成员 ID、分组 seed 和 holdout，新增成员不自动加入旧 snapshot。
3. submit/dispatch 服务端冻结 hash，发送前再次读取 suppression/consent/verified/频控/quiet hours/预算。
4. 只在 test/demo outbox 生成 attempt；live connector 缺失返回 external_blocked，报告保留 assigned/holdout/skipped。
