# UI navigation simplification — ExecPlan

## Goal

Reduce the visual and interaction load of the authenticated workbench sidebar while preserving every existing page entry, role gate, route, and mobile menu behavior.

## Scope

- Group the sidebar into 工作台、经营、内容、现场、系统.
- Remove decorative row numbering/arrows from the visual layout.
- Keep the sidebar sticky without a nested scrollbar on desktop.
- Keep the existing two-column mobile menu and menu toggle.

## Validation

- [x] Compile the web bundle with `npm run build`.
- [x] Run the repository unified validation gate.
- [x] Reload the local complete demo and inspect the admin overview; verify the POS 与指标 route and return to 总览.
- [ ] Recheck the two-column menu at a viewport below 850px during the next responsive review.

## Risks / follow-up

- This is a navigation presentation change only; permissions and page routing remain in the existing controller.
- The browser check is visual/DOM validation in the local demo and is not a native browser E2E claim.
