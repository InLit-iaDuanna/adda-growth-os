# TEST_DATA_2026_09_26

## 目标和用户可见结果

提供一套可重复生成、只含合成资料的完整 demo 测试数据，覆盖登录、品牌、产品价格、素材、内容审核、来源链接、注册领券、POS/退款、校园活动、CRM、顾客声音和 Agent 证据。交付物包括隔离 JSON 仓储、三份可导入 CSV、账号/token manifest、甲方原图副本、可复核说明和验证记录。

## 仓库现状与依赖

项目当前实际运行时是 Node HTTP + JSON 文件仓储；生成器必须复用编译后的领域合同和 `seed-demo.js`，不能伪装成 PostgreSQL 或真实渠道初始化。输入素材来自用户给出的本机临时图片目录。验证依赖已安装的 Node 22、TypeScript 编译产物和本机演示服务；外发、支付、WhatsApp 和真实发布保持关闭。

## 设计与文件路径

- `scripts/seed-complete-test-data.mjs`：从干净演示种子构建快照，写入 `data/complete-demo.json` 与 `artifacts/test-data/`。
- `scripts/verify-complete-test-data.mjs`：重算指标、检查审批/令牌/CSV/Agent 运行，并可用 `--server` 做 HTTP 登录检查。
- `artifacts/test-data/complete-demo.json`：可直接加载的合成仓储。
- `artifacts/test-data/{members,orders,refunds}.csv`：可在运营端预览/提交的导入样本。
- `artifacts/test-data/manifest.json`：固定 demo 账号、token、ID、覆盖数量和限制。
- `artifacts/test-data/assets/originals/`：用户提供的 11 张原图副本。
- `artifacts/test-data/validation.json`：最近一次离线领域与隔离 HTTP 验证记录。

## 实施步骤

1. 读取干净 `seed-demo.js`，清空业务集合并写入合成租户、门店、账号和品牌/菜单资料。
2. 写入时间一致的会员、来源、订单、退款、优惠券、内容、活动、CRM、反馈和 Agent 数据。
3. 通过 domain 的 `captureContentFacts`、`queryMetrics`、`outreachApprovalHash`、`commandControlRun` 等函数生成不可伪造的绑定值。
4. 计算 CSV 文件哈希、生成 manifest，原子写出 JSON/CSV/manifest，并复制原图。
5. 启动隔离 Web 服务，验证角色登录、内容导出、来源 offers、收银保留/匹配和 CSV 预览。

## 实际验证证据

最近一次记录在 `artifacts/test-data/validation.json`，包含 8 项检查：合成租户、计算指标、可执行内容审批、优惠券/CRM 哈希、CSV 解析和文件哈希、4 个 durable Agent runs、环境 secret 隔离、三类账号 HTTP 登录。隔离服务使用 `127.0.0.1:3111`，未执行外部写入。

## Surprises & Discoveries

- 初版手写报表引用了 report policy 不可见的 attribution/outreach ID；改为真实 metric ID 后报告可读取。
- 初版内容审批的素材权利哈希和 coupon token 与运行时算法不一致；改为调用实际 domain 规则后，内容 export 与收银 token 才能复用。
- 指标显示值是 64,000 BDT 净营收、4 个合格订单、75% 身份覆盖、50% 30 日复购、1/3 注册后 7 日转化；这些值由当前快照重算。
- 应用服务的当前运行时数据使用 `data/complete-runtime.json` 副本，避免验证操作污染交付 fixture。

## Decision Log

- 只使用合成姓名、`.invalid` 邮箱和明确测试标签；不把未知素材授权写成已批准。
- 继续使用现有 JSON 仓储以匹配仓库可运行实现，不在本任务中声称完成目标架构迁移。
- 运营工作台和顾客流程共享固定 demo secret；manifest 明确这是 bearer token，只能本机演示。

## 回滚与幂等

生成器只允许创建或覆盖带 `test_data.fixture_seeded` 审计标记且为 demo 模式的文件；生产模式直接拒绝，存在 `.lock` 也拒绝。输出先写临时文件再原子替换。要回滚演示数据，删除 `data/complete-demo.json` 后重新执行生成器；运行服务使用副本，不会修改 artifact。
